# 🏥 Medical Bot - Replit UI

A beautiful, modern medical bot interface with AI-powered chat and patient management.

## ✨ Features

- **🎨 Beautiful UI**: Modern design with Tailwind CSS
- **🤖 AI Chat**: Claude-powered intelligent responses
- **👥 Patient Management**: Search and view patient data
- **📊 Dashboard**: Real-time statistics and overview
- **🔍 Smart Search**: Find patients by name, ID, or contact
- **💬 Real-time Chat**: Interactive AI assistant
- **📱 Responsive**: Works on all devices

## 🚀 Quick Start

### **Option 1: Local Development**
```bash
# Navigate to replit-ui directory
cd replit-ui

# Install dependencies
npm install

# Start the server
npm start
```

### **Option 2: Replit Deployment**
1. **Create new Replit project**
2. **Upload all files** from `replit-ui/` folder
3. **Add environment variables**:
   - `ANTHROPIC_API_KEY=your_api_key_here`
4. **Run**: `npm start`

## 🔧 Setup

### **1. Environment Variables**
Create a `.env` file:
```bash
ANTHROPIC_API_KEY=sk-ant-your-api-key-here
PORT=3001
```

### **2. Database Setup**
The app will automatically use the existing database from the parent directory.

### **3. Start Server**
```bash
npm start
```

## 🎯 Usage

### **Access the UI**
- **URL**: http://localhost:3001
- **Features**: Patient search, AI chat, statistics

### **Chat with AI**
1. **Click the chat button** (bottom-right)
2. **Ask questions** like:
   - "Show me all patients"
   - "Who is the oldest patient?"
   - "What insurance providers do we have?"
   - "Find patient by ID"

### **Search Patients**
- **Use the search bar** to find patients
- **Search by**: Name, ID, phone number
- **Click patient cards** for details
